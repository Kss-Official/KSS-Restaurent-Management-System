# Frontend - Restaurant Management System

This is the frontend client for the Restaurant Management System, built with React and Vite.

## Project Structure

- `public/` - Static assets served as-is
  - `favicon.ico` - Browser tab icon
  - `index.html` - HTML shell React mounts into
- `src/` - React source code
  - `api/` - Axios setup and API call functions
  - `assets/` - Images, fonts, and icons
  - `components/` - Reusable UI building blocks (common, layout)
  - `features/` - Domain features (auth, dashboard, users)
  - `hooks/` - Custom reusable React hooks
  - `routes/` - URL routing setup and route guards
  - `store/` - Global state management
  - `utils/` - Helper functions and constants
  - `App.jsx` - Root application component
  - `main.jsx` - React entry point
  - `index.css` - Global stylesheet
- `.env` - Frontend environment variables
- `.gitignore` - Git ignore file
- `package.json` - Frontend dependencies and scripts
- `vite.config.js` - Vite build configuration
